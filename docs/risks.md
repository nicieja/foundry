# Risks

Facts about the world that can stop the project, each with the scale at which it starts to matter. Append-only, newest last. The doctrine is `docs/engineering/risk.md`.

A risk is registered the moment it is named, by whoever names it. One line each:

`- <the risk> — bites at: <observable threshold> — clears by: <what would settle it> — status: open | cleared | hit`

The threshold is a number or an event the loop can check: the first real payment, the first stored password, a rung that passes. *When we are bigger* is not a threshold. A risk whose threshold the current release already meets is not deferred — it is the work.
